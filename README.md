# Ashworth & Vale — Fine Real Estate

A premium real estate website created as part of my **Full-Stack Developer Internship at Suusri AI**.

The project focuses on a sophisticated luxury real-estate experience with responsive layouts, elegant typography, interactive property listings, animations, and dark/light theme support.

### ✨ Highlights

* Luxury real-estate website with responsive design
* Property listings with category filtering (Villas, Apartments, Plots, Commercial)
* Dark / Light mode with localStorage persistence
* Property image gallery with lightbox (Keyboard & Nav support)
* Smooth scroll and UI animations (Scroll-reveal, Cinematic Zoom, Button Shine)
* Animated Statistics counters
* Responsive mobile navigation with slide-out panel
* Contact / enquiry form with client-side validation
* Interactive Testimonial Slider
* FAQ Accordion
* Custom scroll progress bar and Back-to-top button
* Premium Elegant Typography (Fraunces & Public Sans)

### 🛠️ Built With

* HTML5
* CSS3 (Custom Properties/Design Tokens for theming)
* JavaScript (Vanilla JS - Intersection Observer, Theme Toggle, Form Validation)
* Google Fonts
* Inline SVG Icons
* Unsplash Images
* OpenStreetMap Integration (Embedded map on Contact page)

### 📂 Pages

* **Home** — Hero section, animated statistics, featured properties, why-choose-us, testimonials & CTA
* **Properties** — Category tiles, property listings, dynamic filters, detailed gallery & lightbox
* **Agents** — Agent profiles
* **Contact** — Contact information, interactive map, enquiry form with validation & FAQ
